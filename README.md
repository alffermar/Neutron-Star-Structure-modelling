# Neutron Star Structure Modelling

This project implements a dense nuclear matter model to study the equation of state (EoS) of a neutron star and solve the Tolman–Oppenheimer–Volkoff (TOV) equations to obtain mass–radius profiles.

The code is written in Fortran and is organized into modules to separate the main physical and numerical components:
- physical constants and model parameters,
- equation-of-state functions,
- numerical methods,
- nonlinear system solution,
- TOV integration.

## Problem description

The program solves a nonlinear system associated with a hadronic matter model including sigma, omega, and rho mesons, with possible contributions from pions and leptons. Starting from the baryon density, it computes:
- mesonic potentials,
- proton, neutron, and lepton densities,
- energy density and pressure,
- the equation of state stored in `EoS.dat`.

This EoS is then used to integrate the TOV equations and determine the stellar structure, including:
- radius,
- gravitational mass,
- radial pressure,
- density profile.

## Repository structure

- `precision.f95`: defines the numerical precision (`real128`).
- `Constants.f95`: physical constants, particle masses, and model parameters.
- `Funciones.f95`: definitions of densities, chemical potentials, system equations, energy density, pressure, and TOV derivatives.
- `NumMethods.f95`: interpolation, Jacobian construction, iterative solvers, and RK4 integration routines.
- `SistemaEcuaciones.f95`: solves the nonlinear system for different baryon densities.
- `TovsSolver.f95`: integrates the TOV equations using the generated EoS.
- `Bulk.f95`: computes quantities related to compressibility and effective mass behaviour.

## Requirements

- A Fortran compiler compatible with F2008 (for example, `gfortran`).
- A Linux/macOS/Windows development environment with Fortran support.
- Output files generated by the program (for example `EoS.dat`, `masas.dat`, etc.).

## Compilation

Each program can be compiled separately. For example:

```bash
gfortran -O0 -g -o sistema_ejemplo precision.f95 Constants.f95 Funciones.f95 NumMethods.f95 SistemaEcuaciones.f95
gfortran -O0 -g -o tov_solver precision.f95 Constants.f95 Funciones.f95 NumMethods.f95 TovsSolver.f95
```

To compile `Bulk.f95`:

```bash
gfortran -O0 -g -o bulk precision.f95 Constants.f95 Funciones.f95 NumMethods.f95 Bulk.f95
```

## How to run

1. Compile `SistemaEcuaciones.f95`.
2. Run the generated binary to produce the matter-model output files.
3. Verify that `EoS.dat` has been generated.
4. Compile and run `TovsSolver.f95` using that equation of state.
5. Inspect the output in `Radio-Masa.dat` and the generated `.dat` files.

## Main outputs

- `EoS.dat`: energy density and pressure as a function of baryon density.
- `Preasure.dat`: pressure versus density.
- `Energydensity.dat`: energy density versus density.
- `momentos.dat`: meson field values.
- `poblaciones.dat`: proton, neutron, and lepton fractions.
- `Radio-Masa.dat`: stellar radius and mass for different TOV integration points.

## Model notes

- The baryon density is denoted as `nb` and is expressed in dimensionless units inside the model.
- The equation of state is constructed from the energies of fermions in the presence of mesonic fields.
- The TOV integration is performed using a fourth-order Runge–Kutta scheme.
- The code uses cubic interpolation and iterative methods to solve the nonlinear equations.
