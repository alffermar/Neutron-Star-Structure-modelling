# Neutron Star Structure Modelling

This project implements a dense nuclear-matter model to study the equation of state (EoS) of neutron-star matter and to solve the Tolman–Oppenheimer–Volkoff (TOV) equations. The main outputs are the stellar mass–radius relation and other properties of neutron-star matter.

The code is written in Fortran and is accompanied by Python scripts for visualising the results.

## Overview

The project solves a nonlinear system based on a hadronic matter model that includes the sigma, omega, and rho meson fields, together with possible pion and lepton contributions. For a given baryon density, the model computes:

- meson mean fields,
- proton, neutron, and lepton densities,
- chemical potentials,
- energy density and pressure,
- the equation of state stored in `EoS.dat`.

The resulting EoS is then used to integrate the TOV equations and determine the structure of a neutron star, including its radius, mass, pressure profile, and density profile.

## Repository structure

### Fortran source files

- `precision.f95`: defines the working floating-point precision (`real128`).
- `Constants.f95`: defines physical constants, particle properties, model parameters, and numerical parameters.
- `Funciones.f95`: defines particle densities, chemical potentials, mean-field equations, energy density, pressure, and the derivatives used in the TOV equations.
- `NumMethods.f95`: contains numerical derivatives, interpolation routines, Jacobian construction, Broyden's method, matrix methods, linear-system solvers, and fourth-order Runge–Kutta integration.
- `SistemaEcuaciones.f95`: solves the nonlinear system for the range of baryon densities defined in `Constants.f95` and generates the equation-of-state data.
- `TovsSolver.f95`: integrates the TOV equations using the generated equation of state.
- `Bulk.f95`: computes quantities related to the bulk modulus and the effective nucleon mass.

### Python scripts

- `Sistema.py`: plots the relative populations of the fermionic species and the mean values of the bosonic fields as functions of the baryon density.
- `Estructura.py`: plots the equation of state, \(P(\varepsilon)\), and the mass–radius relation.
- `Termodinamica.py`: plots the bulk modulus and the effective nucleon mass as functions of the baryon density.

## Requirements

- A Fortran compiler with support for Fortran 2008 or later, such as `gfortran`.
- Python 3 for the plotting scripts.
- The Python packages required by the plotting scripts, typically including `numpy` and `matplotlib`.
- A Linux, macOS, or Windows environment with Fortran and Python support.

## Compilation

The Fortran modules must be compiled before the programs that use them. The following commands compile the modules and then build the nonlinear-system solver:

```bash
gfortran -c precision.f95 Constants.f95 Funciones.f95 NumMethods.f95
gfortran precision.f95 Constants.f95 Funciones.f95 NumMethods.f95 SistemaEcuaciones.f95 -o SistemaEcuaciones.exe
```

To build the other programs, replace `SistemaEcuaciones.f95` with the desired source file and change the output name. For example:

```bash
gfortran precision.f95 Constants.f95 Funciones.f95 NumMethods.f95 TovsSolver.f95 -o TovsSolver.exe
gfortran precision.f95 Constants.f95 Funciones.f95 NumMethods.f95 Bulk.f95 -o Bulk.exe
```

For debugging, useful compiler options include:

```bash
gfortran -Wall -Wextra -fcheck=all -O0 -g \
  precision.f95 Constants.f95 Funciones.f95 NumMethods.f95 TovsSolver.f95 \
  -o TovsSolver.exe
```

## How to run

The usual workflow is:

1. Compile and run `SistemaEcuaciones.f95` to solve the matter equations.
2. Check that `EoS.dat` and the other equation-of-state output files have been generated.
3. Compile and run `TovsSolver.f95` using the generated EoS.
4. Compile and run `Bulk.f95` if bulk properties are required.
5. Run the Python scripts to generate plots from the output files.

The programs expect their input and output data files to be available in the working directory from which they are executed.

## Main output files

- `EoS.dat`: baryon density, energy density, and pressure.
- `Preasure.dat`: pressure as a function of baryon density.
- `Energydensity.dat`: energy density as a function of baryon density.
- `momentos.dat`: particle momenta and meson-field values.
- `poblaciones.dat`: particle populations or fractions.
- `Radio-Masa.dat`: stellar radius, mass, pressure, and the final integration index for each central pressure.
- `bulk_mass.dat`: bulk-related quantities generated by `Bulk.f95`.

## Numerical methods

The project uses the following numerical techniques:

- Broyden's method for solving the nonlinear system.
- Finite differences for numerical Jacobians.
- Cubic-spline interpolation for the equation of state.
- A fourth-order Runge–Kutta method for integrating the TOV equations.
- Direct matrix methods based on LU factorisation for selected linear systems.

## Model notes

- The baryon density is represented by `nb` and is expressed in the model's internal dimensionless units.
- The equation of state is constructed from fermionic contributions in the presence of mesonic mean fields.
- The TOV equations are integrated in kilometres using the conversion factors defined in `Constants.f95`.
- The model parameters and the density grid are defined in `Constants.f95`.
- Some variable names, comments, and output filenames are retained from the original Spanish-language implementation.

## Limitations and development notes

- The implementation is intended for research and educational use and should be numerically validated before being used for scientific production results.
- The nonlinear solver and interpolation routines should be tested carefully for convergence, out-of-range input values, and numerical stability.
- The code currently relies on fixed-size arrays and hard-coded file names in several places.
- The output file formats and physical units should be documented further as the project develops.
